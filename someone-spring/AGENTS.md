# 《누군가의 봄》 작업 규칙

이 문서는 `someone-spring/` 전체에 적용된다. 저장소 루트의 `AGENTS.md`와 `CASTING-STANDARD.md`를 함께 따른다.

## 현재 기준

- 현재 버전은 23세 여대생이 학교 연계 장애인 봉사활동에서 성인 남성을 만나는 이야기다.
- 여자 주인공은 165cm, 52~53kg이며 후보 07의 자연스럽고 선한 인상을 기준으로 한다.
- 현재 캐스팅 기준본은 `characters/candidates/CANDIDATE-07/body-profile.png`이며 가상 배우명은 윤하린이다.
- 후보 프로필 제작은 캐스팅 확정을 뜻하지 않는다. 사용자가 명시적으로 승인하기 전에는 모든 후보 상태를 `검토 중`으로 유지한다.
- `characters/CASTING.md`는 특정 배우의 페이지가 아니라 작품 전체 캐스팅 보드다. 새 캐릭터와 배우 후보를 모두 이 보드에 누적한다.
- 후보별 `README.md`는 해당 배우의 한 장짜리 프로필만 보여주는 하위 페이지로 사용한다.
- 남자 주인공은 휠체어를 이용하지만 생활과 취향, 자존심이 분명한 독립적인 성인이다.
- 관계는 봉사자와 이용자에서 시작해 친분, 사적 연락, 봉사 외 만남, 감정 자각 순으로 천천히 발전한다.
- 장애를 동정이나 감정 자극 장치로 사용하지 않는다.

## 폴더 경계

- 이 작품의 모든 파일은 `someone-spring/` 안에서만 만들고 수정한다.
- 다른 작품의 `characters/`, `episodes/`, 이미지와 프롬프트를 가져오거나 연결하지 않는다.
- 《월급날 이후》의 서울 오피스 주인공 이미지는 이 작품의 캐릭터 자료가 아니다.
- `archive/`는 구버전 보관 전용이며 새 회차 제작의 기준으로 사용하지 않는다.
- 구버전 EP.08·09의 얼굴은 후보 07을 캐릭터화한 출처 기록일 뿐이며, 앞으로는 후보 07의 현재 바디 프로필과 내부 정체성 원본을 직접 사용한다.

## 기준 파일

- 작품 설정: `series-bible.md`
- 캐릭터와 캐스팅: `characters/`
- 현재 회차: `episodes/`
- 구버전: `archive/`

캐릭터나 회차를 수정할 때 관련 기준 파일을 같은 커밋에서 함께 갱신한다.
