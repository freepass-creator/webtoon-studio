# 후보 07 · 윤하린 제작 기준과 이력

- 가상의 23세 한국인 여대생
- 부드러운 타원형 얼굴, 크고 순한 눈, 자연스러운 볼선
- 가벼운 앞머리와 긴 짙은 갈색 웨이브 머리
- 165cm, 52~53kg의 건강하고 균형 잡힌 체형
- 얼굴, 체형, 키와 피부색을 모든 테스트에서 동일하게 유지
- 실제 인물을 복제하지 않음
- 공통 단일 바디 프로필 규격 `CASTING-BODY-v2.0` 적용
