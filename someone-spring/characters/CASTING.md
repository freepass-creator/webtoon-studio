# 《누군가의 봄》 캐스팅

공통 절대규격 `CASTING-ABS-v1.0`을 사용한다.

## 여자 주인공

- 기준 후보: [후보 07](candidates/CANDIDATE-07/profile.md)
- 배역: 23세 여대생
- 키·체중: 165cm, 52~53kg
- 인상: 자연스럽고 선한 인상
- 상태: 이야기 기준 후보로 선택됨. 절대척도 프로필과 세부 테스트는 미제작.

## 남자 주인공

- 성인 남성
- 휠체어 이용
- 후보 미정

## 승인 순서

얼굴 → 절대척도 체형 → 의상 → 포즈·표정 → 두 사람의 관계 연기 순으로 확정한다.
