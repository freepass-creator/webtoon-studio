# 구버전 보관함

현재 연재 기준이 아닌 이전 자료다.

- [`old-version/`](old-version/README.md): 기존 EP.08·09와 코드 재구성본
- [`legacy-next-app/`](legacy-next-app/README.md): 26세 회사원 한서윤 설정의 이전 Next.js 실행 코드
- [`legacy-static/`](legacy-static/): 이전 HTML 화면
- [`drafts/`](drafts/): 통합 전 이야기 초안
- [`broken-assets/`](broken-assets/README.md): 열리지 않던 손상 이미지 원본

새 캐릭터나 회차를 만들 때 이 폴더의 설정과 이미지를 기준으로 사용하지 않는다.
