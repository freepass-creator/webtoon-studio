# Joseon Palace Drama 작업 지침

이 파일은 `joseon-palace-drama/` 아래에서 작업하는 모든 Codex 세션의 공통 기준이다. 캐릭터 후보, 복식 테스트, 에피소드 이미지를 만들기 전에 반드시 먼저 읽고 따른다.

## GitHub 원본 우선

- 모든 이미지 생성·수정 결과의 기준 원본은 GitHub 저장소 `freepass-creator/webtoon-studio`에 둔다.
- 결과는 `joseon-palace-drama/`의 해당 캐릭터 또는 에피소드 폴더에 저장하고 커밋까지 완료한다.
- GitHub에서 파일이 정상적으로 열리는지 확인한 뒤 채팅에는 GitHub 저장본만 보여 준다.
- 후보 사진은 폴더 링크가 아니라, 누르면 이미지 자체가 열리는 GitHub raw 링크로 제공한다.
- 완성 에피소드는 누르면 휴대전화에서 세로 스크롤로 바로 읽히는 배포 링크로 제공한다.
- 승인본을 조용히 덮어쓰지 않는다. 수정본은 버전 파일 또는 명확한 커밋 이력으로 남긴다.

## 작품 기준

- 조선 초기풍 가상 왕조를 배경으로 한 장기 연재형 실사 웹툰이다.
- 실제 왕·왕비·후궁을 성적 서사의 인물로 복제하지 않는다. 이름·가계·사건은 가상으로 설계한다.
- 연애·밀회·성적 긴장이 있는 모든 인물은 명시적인 성인이며, 캐릭터 프로필에 나이를 기록한다.
- 왕과 궁녀·후궁 사이의 권력 비대칭을 서사의 핵심 긴장으로 다루되, 강압을 낭만적 사랑처럼 미화하지 않는다.
- 노골적인 행위보다 시선, 손, 문틈, 옷깃, 숨, 촛불, 발소리와 다음 날의 정치적 결과로 긴장을 만든다.
- 동일 인물의 얼굴, 헤어, 체형, 신체 비율, 피부 톤과 분위기를 전 회차에서 유지한다.

## 시각 방향

- 영화·OTT 사극 스틸에 가까운 사실적 질감
- 달빛의 청색, 촛불의 호박색, 궁중의 먹색과 짙은 자주색을 기본 팔레트로 사용
- 피부를 과도하게 보정하지 않고 천·나무·종이·금속의 실제 질감을 살린다.
- 세로 화면에서 인물의 거리와 문·기둥·발을 이용해 감시받는 느낌을 만든다.
- 복식은 시대 자료를 확인하되, 극적 가독성을 위해 색과 실루엣은 인물별로 분명히 구분한다.

## 캐스팅 코드

- 왕: `KING-01`, `KING-02`
- 왕비: `QUEEN-01`, `QUEEN-02`
- 후궁: `CONSORT-01`, `CONSORT-02`
- 궁녀: `COURTLADY-01`, `COURTLADY-02`
- 상궁: `SANGGUNG-01`, `SANGGUNG-02`
- 호위·문무관 등: 역할 영문명 뒤에 두 자리 번호

사용자가 후보 코드를 말하면 해당 폴더의 인물을 정확히 지칭하는 것으로 처리한다.

## 저장 규격

```text
joseon-palace-drama/characters/candidates/COURTLADY-01/
  face-reference.jpg
  body-turnaround.jpg
  costume-test.jpg
  expression-test.jpg
  chemistry-test.jpg
  profile.md
  prompt.md
```

- 승인 전 후보와 확정 캐릭터를 분리한다.
- 확정 후보만 `characters/main/<역할명>/`에 복사하고 캐릭터 바이블을 만든다.
- 이미지 생성에 사용한 최종 프롬프트와 변형 이력을 `prompt.md`에 기록한다.
- 신분별 복식·가체·장신구·침전 소품은 `references/`의 근거와 함께 관리한다.
- 에피소드 제작 시 확정 캐릭터 바이블을 최우선 정체성 레퍼런스로 사용한다.

## 공통 절대척도 적용

- 모든 캐스팅은 루트 `../CASTING-STANDARD.md`의 `CASTING-ABS-v2.0`을 최우선으로 따른다.
- 공통 6장 템플릿과 바로보기는 `../assets/casting/v2/`에 있으며 프로젝트별로 새 배율이나 새 캔버스를 만들지 않는다.
- 사극 캐스팅복은 미색 가슴싸개와 속바지를 사용할 수 있으나 같은 배역군 후보에게 형태·길이·색을 동일하게 적용한다.
- 현재의 생성형 전신 시안은 후보 탐색용이다. 확정 전에는 01 전체 프로필, 02 절대척도 체형, 03 얼굴·표정, 04 의상, 05 동작, 06 상대역 합의 v2 파일을 순서대로 추가한다.
