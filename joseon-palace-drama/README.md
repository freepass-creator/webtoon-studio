# Joseon Palace Drama

조선 초기의 질감에서 출발하는 가상 왕조 배경의 실사형 세로 스크롤 웹툰 프로젝트.

- 상태: 콘셉트 개발
- 작품명: 미정
- 작업 슬러그: `joseon-palace-drama`
- 장르: 성인 궁중 로맨스 · 미스터리 · 권력 스릴러
- 형식: 모바일 세로 스크롤 장기 연재
- 인물: 연애·밀회 서사에 참여하는 모든 인물은 명시적인 성인 가상 인물
- 방향: 실제 조선 왕실 인물을 재현하지 않고, 조선 초기풍 제도·복식·공간을 참고한 가상 역사극

## 임시 로그라인

피로 왕좌를 얻은 새 왕의 침전으로 매일 밤 서로 다른 여인이 들어온다. 왕의 마음을 얻으려는 후궁, 왕의 약점을 훔치려는 궁녀, 그리고 모든 밀회를 기록하는 상궁. 한 번의 은밀한 부름이 왕실 계승과 조정의 권력 지도를 뒤집는다.
