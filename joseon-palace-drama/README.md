# 조선 궁중극

조선 초기의 질감에서 출발하는 가상 왕조 배경의 실사형 세로 스크롤 웹툰.

## 현재 상태

- 콘셉트 개발
- 장르: 성인 궁중 로맨스 · 미스터리 · 권력 스릴러
- 형식: 모바일 세로 스크롤 장기 연재
- 실제 왕실 인물을 재현하지 않는 가상 역사극
