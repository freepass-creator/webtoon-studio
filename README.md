# 누군가의 봄

실사 컷과 세로 스크롤로 읽는 성인 웹툰. EP.1, EP.8, EP.9가 있습니다.

평범한 회사원 한서윤이 성인권 보조 봉사를 시작합니다. 성행위는 그리지 않습니다. 표정, 손, 반쯤 내려간 바지, 그리고 왜 이 도움이 필요한지만 남깁니다. 서윤은 상대를 사랑하지 않습니다. 그 활동에 빠집니다.

## 실행

```bash
npm install
npm run dev -- --port 43217
```

브라우저에서 [http://localhost:43217](http://localhost:43217) → **EP.1 처음 하는 일 보기**.

## 구성

- `/` 작품 소개
- `/spring/1` EP.1 처음 하는 일
- `/spring/8` EP.8 조금씩, 선이 흐려진다
- `/spring/9` EP.9 더 깊어지는 관계
- `src/data/episode-*.ts` 콘티·대사
- `public/episodes/spring/` 실사 패널
