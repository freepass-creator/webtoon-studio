# 월급날 이후 작업 지침

이 파일은 `college-drama/` 아래의 캐릭터·회차 작업에 적용한다. 작업 전 루트 `AGENTS.md`와 `CASTING-STANDARD.md`를 함께 읽는다.

## 1. GitHub 먼저 저장

- 모든 생성·수정 이미지의 기준 원본은 `freepass-creator/webtoon-studio`에 둔다.
- 결과를 GitHub에 커밋하고 정상 열림을 확인한 다음 사용자에게 GitHub 바로보기 링크를 준다.
- 후보 이미지는 `college-drama/characters/candidates/<후보코드>/`에 저장한다.
- 승인본을 조용히 덮어쓰지 않고 버전 또는 커밋 이력을 남긴다.

## 2. 캐스팅 자료는 후보별 한 장

- 공식 캐스팅 자료는 후보별 `body-profile.png` 한 장만 사용한다.
- 한 장 안에 후보명, 동일 배우의 정면·정확한 옆면·뒷면 전신, 0~200센티미터 키 눈금, 나이·키·몸무게를 넣는다.
- 의상은 모든 후보가 동일한 불투명 흰색 운동용 크롭 래시가드와 흰색 수영 쇼츠를 입는다.
- 맨발·중립 자세·동일 조명·동일 배율로 제작한다.
- 표정, 의상 룩북, 자세, 동작, 호흡 시험은 기본 캐스팅 자료에 넣지 않는다.
- 이전 여러 장짜리 자료는 기록으로 남길 수 있으나 후보 `README.md`에는 펼치지 않는다.
- 이미지 안의 표기는 전부 한글로 쓴다.

## 3. 후보 코드와 현재 후보

- 직장인 주인공 후보 코드는 `OFFICE-01`, `OFFICE-02` 순서로 부여한다.
- `OFFICE-01`의 가상 이름은 **한서윤**이다.
- 현재 설정은 29세, 168센티미터, 55킬로그램이다.
- 사용자가 코드나 이름만 말해도 동일 후보를 뜻한다.

## 4. 주인공 체형과 얼굴 방향

- 29세 한국인 여성 직장인
- 밝은 피부, 자연스러운 볼살, 부드럽고 선한 인상, 약간 또렷한 눈매
- 체중을 줄이지 않은 건강하고 자연스럽게 단련된 체형
- 작은 얼굴과 긴 다리 비율
- 무릎 아래가 곧고 매끄러우며 발목이 정돈된 다리선
- 기존 얼굴 기준 이미지가 있으면 다른 얼굴을 새로 만들지 않고 정체성 기준으로 사용한다.
- 실제 배우를 복제하지 않고 가상의 성인 배우로 제작한다.

## 5. 후보 화면

- 후보 `README.md`에는 공식 바디 프로필 사진 한 장과 위·아래 뒤로가기만 둔다.
- 사진은 화면에서 바로 보이고 누르면 raw 원본이 열려야 한다.
- 내부 설정과 프롬프트는 별도 파일에 보관하며 사용자용 화면에는 노출하지 않는다.
- 확정 후보만 `college-drama/characters/main/`으로 옮겨 캐릭터 바이블에 등록한다.
